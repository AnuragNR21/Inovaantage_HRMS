Expected Columns

The header row can be anywhere near the top of the sheet and is detected automatically. Required: Employee Code OR an employee name column (e.g. "Particulars"/"Name"). Recognized optional columns (any of these names, case-insensitive):

  • Working Days, Present, Absent, Paid Leave, LOP Days, Half Days, Late Marks, OT Hours
  • Basic Salary, HRA, DA, Conveyance, Medical Allowance, Special Allowance, Professional Development, Other Allowance, Food Allowance, Bonus
  • PF/EPF, ESI, Professional Tax/PT, Income Tax/TDS
  • Employer Contribution, Lop (amount), Gross Salary, Remarks
  • Total Earnings, Total Deductions, Net Salary (used exactly as calculated in the sheet if present)

Rows are matched to an existing employee by Employee Code if the sheet has one, otherwise by full name (must match the employee's name in the Employees list exactly, case-insensitive). Unmatched rows are reported before import. Summary/"Total" rows are automatically ignored. Validation never changes payroll data. Multiple files can contribute to the same month while its payroll remains in the validated state. Duplicate employees must be resolved before confirmation.
